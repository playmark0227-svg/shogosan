# ここに画像をアップしてください

生成した画像は、**このフォルダ（`images/_inbox/`）にまとめてアップロード**してください。
その後わたし（Claude Code）に「アップしたよ」と伝えれば、自動で：

1. ファイル名からどのスロットの写真か判定
2. 規定のアスペクト比に中央クロップ
3. 適正サイズにリサイズ・圧縮（300KB以下）
4. `images/` の正しい名前で配置
5. サイトに反映（公開）

まで行います。**このフォルダの中身は取り込み後に自動で消えます**（正常な動作です）。

---

## アップロードの手順（GitHubの画面から）

1. このページ（`images/_inbox/`）を開く
2. 右上の **「Add file」→「Upload files」** をクリック
3. 生成した画像を**まとめてドラッグ＆ドロップ**
4. 下の **「Commit changes」** を押す
5. Claude Code に「アップしたよ」と伝える

---

## ファイル名について

**ゆるくてOKです。** 以下のどれかが名前に入っていれば自動で判定します：

- 正式名（例: `tile-noiru.jpg`）… 一番確実
- 番号（例: `07.jpg`, `image_07.png`）… 指示文の番号と一致していればOK
- キーワード（例: `トリミング.jpg`, `maruyama.png`）

形式は **JPG / PNG / WEBP** どれでも大丈夫です。サイズもこちらで調整します。

判定できなかったファイルは取り込まれず、その旨をお知らせします。
